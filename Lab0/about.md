# О Git

## Что такое Git и для чего он используется?

Git — это распределённая система контроля версий. Она позволяет отслеживать изменения в файлах проекта, сохранять историю изменений и возвращаться к предыдущим версиям. Git также удобен для совместной работы над проектами.

## В чём разница между централизованными и распределёнными системами контроля версий?

В централизованной системе основная история проекта хранится на одном сервере. В распределённой системе каждый разработчик имеет собственную копию репозитория вместе с историей изменений и может работать с ней локально.

## Что такое репозиторий в Git?

Репозиторий — это место, где хранятся файлы проекта и история их изменений. Git использует репозиторий для хранения коммитов, веток и другой информации о проекте.
