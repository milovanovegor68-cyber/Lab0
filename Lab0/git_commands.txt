1. git init — создание нового локального репозитория.

2. git clone — копирование удалённого репозитория на компьютер.

3. git status — просмотр состояния репозитория.

4. git add — добавление изменений в индекс.

5. git commit — сохранение изменений в истории Git.

6. git push — отправка коммитов в удалённый репозиторий.

7. git pull — получение изменений из удалённого репозитория.

8. git branch — просмотр и управление ветками.

9. git checkout — переключение между ветками или версиями.

10. git merge — объединение веток.

11. git log — просмотр истории коммитов.

12. git diff — просмотр различий между версиями файлов.
